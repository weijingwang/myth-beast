# I Thought Raising a Mythical Beast Would Be Easy, but Somehow I’ve Become the Laughingstock of the Kingdom

A visual novel made for PyWeek 42 (theme: *Borrowed Time*) by Team Chinkaraoshiman.

## About

Visual Novel game about the young lady who wishes a high social standing is met with a mythical beast and now both are living on borrowed time.

## Team

- **chis**: story, planning, writing
- **Apex**: music, sound effects
- **speedlimit35**: art, music, code

Sound effect credits are in `credits.rtf`.
There is a bach excerpt from bwv997 gigue.

## Requirements
We used pygame-ce 2.5.5 and Python 3.12.4

Install:

```
pip install -r requirements.txt
```

or simply `pip install pygame-ce`.

## How to play

```
python main.py
```

Click, or press Space or Enter, to advance the story. Click a button to make a choice. There are 4 endings.
